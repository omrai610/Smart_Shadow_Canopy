⚡ ESP32 & Wokwi Simulation Setup

You can run the real ESP32 code inside the free online Wokwi Simulator with zero hardware needed! It connects to HiveMQ and streams live directly into this dashboard.

Step 1: Open Wokwi ESP32 Project

  1. Go to wokwi.com/projects/new/esp32.
  2. In sketch.ino, paste the provided ESP32 firmware code.
  3. In diagram.json tab (or press F1 > View diagram.json), paste the canopy wiring JSON below.

Step 2: Install Libraries in Wokwi (diagram.json)

In Wokwi's "Library Manager" tab, search and add:

  • PubSubClient by Nick O'Leary
  • DHT sensor library by Adafruit
  • ESP32Servo by Kevin Harrington

Step 3: Hardware Pinout Wiring Summary
